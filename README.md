# Student Performance Analytics System

## Project Overview
The Student Performance Analytics System is a Python-based data analysis project that analyzes student marks and attendance to understand academic performance. It uses Pandas and NumPy to process student records and generate meaningful results.

## Technologies Used
- Python
- Pandas
- NumPy
- CSV Dataset

## Dataset
The dataset contains 100 sample student records from IT and CS departments, including:
- Student ID and Name
- Department
- Python, SQL, Excel, and Power BI marks
- Attendance percentage

## Key Features
- Calculate total and average marks for each student.
- Assign grades based on average marks.
- Identify pass and fail students.
- Calculate the highest, lowest, and overall class average.
- Analyze average marks for each subject.
- Identify top-performing students.
- Export analyzed results to a CSV report.

## Project Structure
- `main.py`: Main program for student performance analysis.
- `students.csv`: Dataset containing student records.
- `student_analysis_report.csv`: Generated analysis report.

## How to Run the Project

1. Install the required libraries:

   `pip install pandas numpy`

2. Make sure `main.py` and `students.csv` are in the same folder.

3. Run the program:

   `python main.py`

4. View the analysis in the terminal and check the generated CSV report.

## Objective
The objective of this project is to practice Python programming, data handling, numerical calculations, and data analysis using Pandas and NumPy.

## Expected Outcome
The system provides a clear summary of student performance, subject-wise averages, grades, pass/fail results, and top performers.
